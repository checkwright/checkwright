# SPEC amendment: ambient-diagnostic

Queue entry: `editor-diagnostic-unruled`. Taken at its recurrence threshold into unit set
`resident-tier-restatement` under **operator direction, 2026-09-13, lead-relayed**, on the ground
that both named candidate homes are that set's surfaces.

## What the probes returned before any shape was chosen

The entry is a mitigation question about a tool this repo does not control, so the doctrine's
*a third-party tool's behavior is a configuration question first* rule binds before design: probe
the configuration surface and the issue tracker, and design only what is left. Both came back
non-empty.

- **Configuration.** The channel is a language-server plugin installed at the operator's user
  scope, before the entry's first instance; the project's tracked settings carry no plugin key. So
  the channel is mutable per project by a harness settings edit — which only the operator
  authorizes, so no stage session takes it.
- **Issue tracker.** The harness's own tracker carries an **open**, root-caused report that its
  LSP client never sends `workspace/didChangeWatchedFiles`, so a module created mid-session yields
  phantom diagnostics that never clear, and the reporter names the harm this entry names — the
  agent "tries to fix code that is already correct". The entry's instances 3 and 4 are exactly
  that shape: the first two module-adding commits of an iteration, reported as private-import
  errors on the new modules. **The defect is reported; no surface of this unit proposes reporting
  it.** The two structurally impossible reports of 2026-09-12 are not explained by that report
  alone, and no probe here settles them; they are stated as unexplained rather than attributed.

What is left after both probes is the part no configuration reaches: **every consumer's harness
may carry such a channel, configured or not, and the doctrine's oracle rule does not name it.**
Silencing this repo's channel would leave the class unruled for every adopter, and ruling the class
leaves the channel's usefulness where the operator installed it. So the design is the doctrine
clause.

**Disposition — operator direction, 2026-09-13, lead-relayed:** the doctrine clause and the
resident `native/` clause, with the plugin and every settings file left untouched. Disabling the
channel for this project, alone or beside the clause, was put to the operator and not chosen.
**Lead decision, same day:** the 2026-09-12 reports naming symbols that exist nowhere are filed as
a costed gap rather than folded in, and the one hypothesis offered for them — crate copies in agent
worktrees — stays unverified there.

## What changes

### (1) Oracle-first names an ambient diagnostic as a non-oracle {design-bearing}

`doctrine-kit/DOCTRINE.md` rule 8 *Oracle-first* gains one clause in each of its three parts. The
rule already refuses one wrong oracle — gate source read to predict a verdict — and one wrong
replica — a newer local toolchain; an ambient channel is the third, arriving unasked. **Not yet
applied.**

After *"Gate source is opened to fix the gate or write its fixtures, never to predict its
verdict."*:

> Nor is a diagnostic the session did not run an oracle: an editor or language-server report the
> harness surfaces unasked answers to no pinned toolchain and no snapshot the session controls, so
> one contradicting the oracle is settled by re-running the oracle, never by editing code the
> oracle passed.

Appended to *Under agent work*:

> An ambient report is the cheapest wrong oracle to trust, because it arrives in context
> unrequested and in a compiler's voice.

Appended to *Enforced by*:

> Whether a session acted on an ambient report leaves no residue in the tree, so that clause is
> judgment.

The `*Digest:*` trailer is **unchanged** — *run the gate, never emulate it; a red run is the
feedback channel* — so no consumer's installed digest moves and `check-doctrine-registration`
assertion F reads the same value. A digest clause was weighed and refused: it would put a
harness-specific channel on every consumer's resident surface, which delta 2's narrower resident
line covers for the one tree where the channel has fired.

Placement is the widest true tier: the clause names no harness, plugin or language, so it holds for
every consumer, and the provenance seam is not in reach.

### (2) The resident line where crate commits are instructed names the channel {mechanical}

`CLAUDE.md`'s `native/` bullet already carries the commit-time obligation — the battery **plus**
`bash gate-sdk/bin/build-native.sh`, *neither discharges the other*. That sentence is read at
every crate-touching commit, which is the moment every instance fired, and the doctrine body is not
loaded then. The sentence gains the channel as a third non-discharger: **an editor diagnostic
discharges neither**.

The bullet is also being cut to budget by `context-kit/SPEC-brevity-reach.md`, so **the clause's
text is carried inside that amendment's proposed replacement for the bullet**, and this delta owns
only its content. Whichever batch lands second verifies the clause survived the other.

## Producers and consumers

- **The rule 8 clause** (delta 1).
  - *Producer:* this unit's build, into the doctrine body.
  - *Consumer:* a session reading rule 8 — at authoring or review of oracle-bearing work, and every
    consumer through its vendored doctrine.
  - *Honest limit:* the moment the channel fires, no trigger loads the rule body — which is delta
    2's reason to exist.
- **The resident clause** (delta 2).
  - *Producer:* the build landing `context-kit/SPEC-brevity-reach.md`'s `native/` replacement.
  - *Consumer:* any session committing under `native/`, the population every recorded instance
    came from.
- **No new state, field, knob or gate.**
- **Red conditions** (causal-completeness point 5). No delta narrows a corpus. `DOCTRINE.md`'s
  readers: `check-doctrine-registration` (A–F) reds on a link, name, trailer or digest-text
  mismatch — none moves; `--emit stage-rules` reads craft-register trailers only, rule 8 is a
  methodology rule; `check-manifest-temporal` reds on a narration marker — the text carries none;
  `check-docs-mirror-fresh` reds on a stale mirror — regenerated in the landing commit. `CLAUDE.md`'s
  readers under delta 2 are `context-kit/SPEC-brevity-reach.md`'s to enumerate, since that amendment
  owns the bullet's whole rewrite.
