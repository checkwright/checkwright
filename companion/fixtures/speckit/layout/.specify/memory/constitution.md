# Release Notes Constitution

## Core Principles

### I. Notes come from merged work

Every entry in a release note traces to a merged change. An entry with no change behind it is removed before the release is cut.

### II. One command per release

A maintainer exports the notes for one release with one command, and the command writes nothing outside its output file.

## Governance

This constitution governs every feature under `specs/`. An amendment is a reviewed change to this file, and a feature plan checks itself against it before design starts.
