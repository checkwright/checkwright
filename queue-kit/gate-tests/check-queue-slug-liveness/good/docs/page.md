# Living page

The [live-task](../TASK-QUEUE.md#live-task) work is in flight, and [deferred-task](../TASK-QUEUE.md#deferred-task)
is queued behind it. Bold code like **`landed-task`** is emphasis and claims nothing, and a link
into another file, like [a note](../NOTES.md#landed-task), is no claim on the queue.
