# Queue — the clean forms, copied from live entries that name the record as a subject

- **naming-as-subject-one** — the record is the sentence's subject, not a promise of retrievable content.
  A superseded block sits beside its superseder with no visible difference.
  `.workflow/survey-record.md`'s stage-entry read trigger advertises every block for a
  reader who cannot tell which one is live.

- **naming-as-subject-two** — same shape, path opening a wrapped continuation line after a full stop.
  The selector answered the wrong term, so the ruling failed on both terms.
  `.workflow/survey-record.md` was wrong twice in one iteration, and both firings were found late.

- **naming-as-subject-three** — mid-sentence mention after a full stop on one physical line.
  A liveness scan reads the surface only for emptiness or a bullet count. `.workflow/survey-record.md`
  does both, which is why the count alone proves nothing.

- **naming-as-subject-four** — the record's purpose stated, still no retrieval promise.
  The mechanism claimed more than it held and was wrong three times in one iteration.
  `.workflow/survey-record.md` exists so a later stage need not re-derive a survey,
  which is a reason to keep it rather than a place to send a reader.

- **prepositional-mention** — a path introduced by a preposition, never by a colon.
  The stage cursor has exactly one source, the last stamp in
  `.workflow/WORKFLOW-STATE.txt`, and stage motion never writes the queue.

- **non-member-after-colon** — a colon-introduced pointer at a surface outside the truncated set stays clean.
  The pattern is already shipped:
  `.workflow/audit-roster.txt` is a tracked roster with its own liveness rules.

- **exempt-dead-citation** — the escape hatch: a surface quoting a dead citation verbatim in order to
  describe it. scratch-citation-exempt: this entry documents the defect and must quote it
  `prose-profile` ended "Full finding and its two-command witness: `.workflow/survey-record.md`".
