# SPEC amendment: index-parity

Each kit's site index page, `docs/<kit>/index.md`, restates part of its own kit
README: an Install paragraph and a Quick start fence. It is generated by nothing,
so a kit-README edit leaves the public page silently behind. The entry asked spec
to rule between generating the restated blocks and a parity gate. **This
amendment rules the parity gate, and takes the prose half of the restatement out
first.** The CLAUDE.md enforcement-first rule is that removing the duplication
outranks gating it. What cannot be removed without losing the page's purpose is
gated.

**The measurement the ruling rests on (2026-09-21).**

- **The pages are mostly independent prose, not a mirror.** There are eleven index
  pages (`git ls-files 'docs/*/index.md'`) of 40 to 60 lines each. Of those
  lines, 5 to 8 occur verbatim in the kit README (`grep -Fxf` over non-blank
  lines). The overlap is the H1, two heading tokens and the fenced door command.
- **The headings diverge by name.** The command section is `## Test` in ten
  READMEs and `## Quick start` in gate-sdk's (`grep -n "^## " */README.md`). The
  index pages all say `## Quick start`.
- **One page curates a subset on purpose.** `docs/gate-sdk/index.md` lists 2 of
  the 8 or more arms gate-sdk/README.md §Quick start shows.
- **The restated Install prose is already wrong in kind.** `docs/canon-kit/index.md`
  says "Vendor the `canon-kit/` directory into your repo and register its gates
  in `gates.list`". That is the manual-vendoring door, while the installer's
  `init` is the adopter path. The kit README's numbered Install section is the
  owner, and one click away sits its byte-identical, freshness-gated mirror,
  `docs/<kit>/README.md`, which the page already links.
- **The gateable tokens are few, and all present today.** Every index page names
  3 to 6 arm (`--x`) or kit-knob (`<KIT>_…`) tokens, and every one also occurs in
  the sibling `docs/<kit>/README.md`. The probe was a per-kit
  `grep -oE -- '--[a-z][a-z0-9-]+|\b[A-Z][A-Z0-9]*_(KIT|SDK)_[A-Z0-9_]+\b'` of
  the page, each token checked with `grep -F` against the sibling mirror, and
  every page came back with nothing missing. So the gate lands green.

**Why generation is ruled out.** A generated block would carry README voice onto
an adopter page, and it would need a per-kit heading map (`Test` or
`Quick start`) plus a per-kit subset rule, for gate-sdk. That machinery would be
bigger than the eleven pages it fills. And generation copies the restatement
rather than removing it, which leaves the duplication the doctrine ranks first
standing, and makes it permanent.

**Why the sibling mirror is the comparand, not the kit README.** The mirror
topology (canon-kit/SPEC.md §The reference-link grammar) puts
`docs/<kit>/README.md` beside the index page, byte-identical to the source and
held so by `check-docs-mirror-fresh`. Comparing with the sibling needs no path
mapping at all: the pairing is "the `README.md` in the page's own directory".
The gate therefore carries no layout knowledge beyond the page glob.

## What changes

**Batching.** Delta 1 lands first, or together with delta 2, so the gate's first
run sees the pruned pages. Delta 3 rides with delta 2.

### (1) The index pages point at the README's Install section instead of restating it {mechanical}

**Not yet applied.** In each of the eleven `docs/<kit>/index.md`, the `## Install`
body becomes one sentence pointing at the sibling mirror's install section,
`[Install](README.md#install)`, with gate-sdk's page pointing at
`README.md#quick-start`, since gate-sdk's README has no `## Install`. The sentence
adds, once, that `checkwright init` vendors the kit for you, linking the site's
install page. The `## Quick start` fence stays, because it is the page's one
runnable line, and delta 2 gates its tokens. The page's opening framing prose and
its `## Contracts` pointers stay as they are.

Mechanical: the replacement sentence is fixed, and eleven pages take it. The
oracles are `check-md-refs` (the anchors resolve) and `check-docs-mirror-fresh`
(the mirror is untouched).

### (2) `check-docs-restatement-parity` holds a restating page's tokens to its sibling source {design-bearing}

**Not yet applied.** This is a new canon-kit gate on the native substrate, with a
`good/`+`bad/` fixture pair and `tier=precommit`. A drift is restorable in the
commit that causes it, by editing the page.

- **Corpus:** tracked files matching `CANON_KIT_RESTATEMENT_PAGES`, a new
  indexed knob of pathspecs whose default is empty, meaning no pages and a clean
  line reading `0 pages`. Each page's **source** is the `README.md` in its own
  directory. A page whose directory has none is exit 2 naming it, because a
  declared restating page with no source is a configuration error, not a pass.
- **Tokens:** within the page's code spans and fenced blocks, two classes. The
  first is **arm tokens**, `--` followed by a lowercase letter and then
  `[a-z0-9-]`. The second is **kit-knob tokens**, matched by `check-docs-cmd`
  (B)'s kit-prefix rule and reusing its matcher (the prefix roster derived from
  `gate_kit_roots`). Prose outside code is not scanned, since a narrative
  mention of a flag is not a restated command.
- **Assertion:** every token of either class that the page carries occurs,
  byte-for-byte, somewhere in its source. The page may carry a subset, which is
  gate-sdk's curated two-of-eight, and the gate asserts only that what it names
  is still named there.

**Point 5, the red condition.** Each missing token is a finding naming the page,
the line, the token and its source. The clean line counts pages and tokens, so an
armed corpus whose pages carry no code tokens shows `0 tokens` rather than
passing unseen. A page glob matching nothing is a legitimate clean `0 pages`, and
not a finding: the knob is the consumer's list, and an empty expansion under a
set knob is visible on that line.

**The honest limit, in the section.** The gate catches a renamed or removed arm
or knob. It cannot catch a changed install *step* told in prose, which is why
delta 1 removes that prose rather than leaving it for a gate that cannot read it.

**Not yet applied.**

## Producers and consumers

- **The pruned pages (delta 1).** Readers: the site's adopters, and
  `check-md-refs` (anchors). `check-door-binding` assertion C still scans them,
  and the remaining Quick start fence is the same door it already accepts.
- **`CANON_KIT_RESTATEMENT_PAGES` (deltas 2 and 3).** Producer: canon-kit's static
  table default (empty), and this repo's knob file. Consumer: the gate. The knob's
  value is the gate's corpus, so the descriptor carries
  `knob:CANON_KIT_RESTATEMENT_PAGES` beside a literal `*/README.md` for the
  sources (gate-sdk/SPEC.md §The `# graph:` manifest, the `knob:` token).
  Roster-holding readers:
  - `check-knob-citation`, satisfied by the SPEC row;
  - `check-docs-cmd` (B), which finds the knob in canon-kit's static roster;
  - `check-install-disposition`, which the gate satisfies with `# install:
    zero-config`, since an empty default scans nothing.
- **`check-docs-restatement-parity` (delta 2).** Consumers:
  - the battery and the hook;
  - canon-kit/README.md's `gate-roster` block, a roster-holding reader
    (`check-readme-roster`), which gains the line;
  - the fixture runner.
- **Point 6.** The corpus is the eleven pages, and each one's satisfying value is
  its present token set, all found in its sibling mirror by the probe above. No
  member is narrowed past.

      causal-completeness check holds for each new state, event, interface and

- [ ] **Instruction surfaces: instruction only.** The pointer sentence carries no
      grounds.
- [ ] **Merged with no information lost.** The removed Install prose loses no
      fact the README mirror does not carry. Build diffs each removed paragraph
      against its README's `## Install`.
- [ ] **Amendment deleted.** This file is removed on merge
      (`ls canon-kit/SPEC-*.md`).
- [ ] **Entry moved.** `docs-index-front-door-restatement-ungenerated` moves to
      Done in the merge commit, at a stage before the drain stage.

      its sibling lacks, and on a declared page with no sibling source.

      above.
