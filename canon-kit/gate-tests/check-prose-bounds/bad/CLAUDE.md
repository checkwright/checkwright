# CLAUDE.md — an agent file with an unbounded paragraph section

## Conventions

- **One owner per fact** — point, never restate.

## Housekeeping

The scratch directory is disposable, and the scope boundary wipes it at every iteration start. The measurement directory persists across iterations and is never committed to the tree. The workflow directory holds tracked projections beside gitignored capture, and each file there names its contract in a header line. The local-only files carry the machine profile, the private brief and the operations notes, and none of them is ever tracked. The reservation placeholder exists to hold a published name, so nobody develops inside it or adds code to it. The native crate is the gate binary's source and is not a kit, since it ships no checks and no smoke directory of its own. Its commit-time obligation is a build plus the battery, and neither one discharges the other. The governed repository metadata is tracked and gated like any document in the tree. The public site is served from its own directory on the default branch, and a load-triggered page owns its chrome and its authoring rules. The installer directory is the published activation surface, and its payload is never committed. A generated projection is never edited by hand, because its freshness gate prints the command that rewrites it. A session that re-derives a fact no document owns stamps that fact in the moment it happens.
