# Methodology

A synthetic living page; its links stay file-targeted.

An off-root target is cited in the absolute self-repo blob form, which the gate
skips as an absolute URL — so the form the rule demands cannot itself red the
rule: [the outside file](https://github.com/owner/repo/blob/master/OUTSIDE.md).

A `../`-prefixed link that resolves back *under* the root is correct and stays
silent, because the rule turns on the resolved path rather than the link text:
[the index](../docs/index.md).
