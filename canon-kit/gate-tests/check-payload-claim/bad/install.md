# Install widget

The kit directories live in your repository as committed source, and a gate
whose implementation is compiled arrives as a binary instead — the near miss
this case pins, since a sentence about what the vendoring model copies stays
true and must not match the overclaiming class.

Two more near misses, both silent: alongside readable source the fixture pair
was a convenience, and there is a difference between vendored source that is
merely committed and vendored source that is auditable.

## Quick start

Download, verify, extract, run. One command, and what governs your tree
afterwards is committed source you can read.

```bash
tar -xzf widget.tgz && bash package/bin/widget.sh init
```
