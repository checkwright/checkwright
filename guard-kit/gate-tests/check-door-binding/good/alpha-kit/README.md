# alpha-kit

Run the gate binary at `GATE_SDK_NATIVE_BIN` with `--emit knob-roster` to print
every default. The kit's own tests are the `--run-gate-tests` arm.

`run-gates.sh` runs gates, not tests — a subject-position mention, not a door.
The front end is still `bin/run-gates.sh` on disk; naming the file is not
invoking it.
