## Bindings

**consistency-gate** — the full gate battery, the bare gate binary at `GATE_SDK_NATIVE_BIN`.

**ritual** — land one self-contained task per session, committed cleanly; the stage stays in `build` until the queue empties. Move a finished task to `## Done` as you go with `--queue done <slug>` (queue-kit/SPEC.md §The queue verbs). A completed task's amendment merges per canon-kit/SPEC.md §Merging an amendment (on task completion). Build to the scope ruling — config surface with this repo's layout as defaults, the provenance seam uncrossed. A unit changing a vendored gate's source or knob-derived set runs `--upgrade-smoke` on its landing commit, before the push, since it reads committed content only: the oracle for an owed Tightened-gates bullet. Stage a new crate source before `build-native.sh` (gate-sdk/SPEC.md §check-gate-binary-fresh).
