## Behavior changes

- **`init`, `--install-doctrine`, `--install-lifecycle` and every arm that writes a marker block** — the block writers now replace the file whole, through a temporary named `<target>.<pid>.<seq>.tmp` renamed over it, keeping the file's permissions, where they used to rewrite it in place. An interrupted `init` or install can no longer leave the agent file torn, and a hard link at a rewritten file keeps its old bytes. A symlinked agent file, such as `CLAUDE.md` linked to `AGENTS.md`, keeps its link: the file it names is rewritten. A link resolving outside its repository, or to no file, is now refused at exit 3 with nothing written. Nothing to do, unless your agent file is such a link: point it at a file inside the repository.
