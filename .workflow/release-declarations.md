## Behavior changes

- **installer `uninstall`, personal install** — the exclude block's removal now also drops the newline its append put on an exclude file whose last line had none, so `info/exclude` reads its pre-install bytes again rather than one newline longer. Nothing to do.
- **installer `init --dry-run`** — no longer creates the gates directory, nor outside a personal install the workflow directory, where an empty one was left behind; it writes nothing. Nothing to do; remove an empty directory an earlier dry run left if you mind it.
- **installer `init --personal`** — the exclude block collapses to one directory line only a kit directory the index holds nothing beneath, where it collapsed any such first component, so a project's untracked files under the gates directory or another directory the install shares stay visible to `git status`. Nothing to do; a re-run rewrites the block.
