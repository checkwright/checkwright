## Behavior changes

- **`uninstall --user`** — now refuses at exit 2, before removing anything, when the binary's path, the knobs directory or a `user.lock` files key passes through a symlink or junction inside the per-user data dir, naming the path and the link, where a forced removal used to delete the file the link reached outside the install. Nothing to do for an install `init --user` made; replace or remove a link you placed there, then re-run.
- **`init`, `init --user` and `uninstall --user`** — a whole-file write's sibling `.tmp` temporary is now created exclusively, any file or link already at its path removed first, so a link there is unlinked where it used to be written through, overwriting the file it reached outside the repository or the per-user data dir; a directory at that path refuses the write, naming it. Nothing to do; remove a directory the refusal names.
- **`--usage-poll`, the statusline producer, the update notice and the run's verdict store** — each whole-file rewrite's temporary is now created exclusively, any file or link already at its path removed first, so a link there is unlinked where it used to be written through, overwriting the file it reached; a directory at that path fails the write. Nothing to do.
- **`wakeup-guard`** — the denial now says the attempt went unlogged, naming the log and the fault, when the attempt log cannot be opened or written, in a repository as with none, where it used to say `Attempt logged.` regardless. Nothing to do; a denial naming a fault points at a log path whose directory is missing or unwritable.
- **`--usage-poll` and the statusline producer** — a rate-limit pair is now held to its shape: a utilization with a stray or doubled dot (`1..2`) or a non-scalar `resets_at` writes no snapshot, so the last good reading survives and ages into STALE, where it used to write one the verdict read with that axis unarmed. The poller takes each pair whole from the flat window object or the nested `rate_limits` one, never one half from each. Nothing to do for a source that sends either shape whole.
- **`--usage-poll` and the statusline producer** — a reset stamp that is a bare calendar day (`2026-11-28`) is no longer read as local midnight: the pair is out of shape and no snapshot is written. The poller also reads a present half that is neither a string nor a number, an object, array or `true`, as out of shape, where a pair of such values used to write a snapshot without that axis, and a malformed flat pair fell through to the nested `rate_limits` one. Nothing to do for a source sending an epoch or an ISO datetime.
- **`--emit stage-economics`** — a price-table row with a `NaN`, infinite or negative price, or an `effective_from` on no calendar (`2026-00-00`, `2026-02-30`), now prices nothing, counted on the meter's skipped-row line and named by line number on `--price-coverage`'s unpriced-row line, where it used to price silently. The other `--emit` arms reading an ISO day hold it to the same calendar check. Fix a row `--price-coverage` names.
