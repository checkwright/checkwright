- 2026-08-01 — GAP (operator-directed, enriches the native-gate-binary-port deferred entry with measured evidence rather than opening work): this iteration produced eleven distinct defects, and sorting them by whether a native port actually removes them gives scope a defensible justification and, more importantly, an honest ceiling. REMOVED BY A NATIVE PORT, four: the shell error model is opt-in, so a probe running under set +e turned a failed gh call into an empty tag list and a zero exit, reporting green forever from its own data source dying; the regex dialect split, where backslash-b is a word boundary in GNU grep and a backspace in POSIX awk, so a predicate silently matched nothing; textual parameter expansion leaving artifacts in derived values; and the heaviest of the four, hand-rolled parsers standing in for real ones, the live instance being check-action-run-shell, which refuses a YAML alias but not a YAML anchor, so a run body written behind an anchor is silently dropped and never linted, a fail-open in the gate whose whole job is linting workflow bash. A real YAML implementation handles anchors by construction; several gates have that same shape. SURVIVES A NATIVE PORT UNCHANGED, seven: git tag reporting green forever under a fetch-depth of 1, which is CI checkout semantics; gh api paginate concatenating pages so a length query returns the last page count rather than the total, which is API semantics; run-gate-tests.sh emitting a success line that reports counts but never names the kit or the files it ran, so the logs of two different kits hash identically and the evidence manifest certifies that some suite ran clean with these counts rather than that this suite ran; presence asserted where resolution was needed, since a trailing-slash URL contains its bare form; a census whose numbers cannot separate a misconfigured tag key from a legitimate pre-release consumer; a SPEC claiming smoke coverage the wiring does not provide; and a required workflow permission with no oracle. CONSEQUENCE FOR SCOPE: justify the port on silent success and on replacing regex approximations with real parsers, not on the vaguer claim that shell is error-prone, and do not sell it as closing vacuous-assertion-count-discipline, because the dominant class here is assertion design and it ports intact. Landing the port and relaxing is the failure mode to design against. THE HARD PART IS DISTRIBUTION, NOT THE LANGUAGE: kits vendor into consumer repos as text with zero build step, and that property is load-bearing for adoption, so a native substrate means shipping a binary via cross-platform distribution, a build dependency, or a package registry; the reserve/ directory already holds the crates.io name reservation, so this was anticipated. A plausible shape is porting the substrate, meaning the runner, the parsers and the assertion primitives, while leaving gates thin, but that is a scope question and is not settled here. Cost while deferred: every iteration keeps paying for hand-rolled parsers and opt-in error semantics, and the entry today carries no measured evidence in either direction, so it gets weighed on intuition.
