- 2026-07-31 — LESSON (lead execution): the agent budget guard gates the root dispatch, not the transitive fan-out. It ran exactly once for the close stage -- at the lead's Agent call, verdict used=92% -> OK -- and close then spawned two Explore children that drew heavily against the same 5h pool. Nothing re-checked between the guard's OK and the wall. Any stage session that fans out multiplies the draw after the only checkpoint, so a per-dispatch guard systematically under-measures exactly the dispatches that cost most. Fix direction is open: re-arm the guard inside a stage session before its own dispatches, or make the lead's dispatch decision budget for the expected fan-out rather than for the stage alone.
- 2026-07-31 — LESSON (lead execution): a guard's OK is a floor, not a recommendation -- and the lead failed to apply its own ruling to itself. The budget guard returned OK at 92% against a 95% threshold with roughly 23 minutes to the 5h reset, and the lead dispatched close, the longest stage in the lifecycle, on that verdict. Waiting for the reset would have cost nothing: there was no deadline. The verdict was treated as a decision rather than as one input to one. This is the same shape as the ruling made earlier in the same iteration about the release note -- that the upgrade smoke's satisfaction is a floor and not the spec, so three Tightened-gates bullets were authored where the oracle demanded one. The principle was stated and then not applied to the lead's own dispatch.
- 2026-07-31 — LESSON (lead execution): model tiering reaches stage dispatches but not their children. The lead's ruling-config tiers what the lead itself dispatches -- validate on the cheaper tier, build tiered per batch on whether any delta is design-bearing -- and says nothing about what a stage session's own sub-agents run on. Close inherited the default tier and its two Explore audit sweeps inherited it in turn, so read-heavy mechanical sweeps ran at the most expensive tier available. Seventh instance of this iteration's scoping lesson, and the first where the rule that failed to reach the unit was the lead's own rather than the repo's: a tiering rule written for one dispatch layer silently exempts every layer below it. Either the tiering rule states what it means for nested dispatch, or a stage session is told to tier its own children.
- 2026-07-31 — GAP (agent-execution protocol): a read-only search sub-agent writes no resume journal, so its findings are un-resumable by construction. The protocol's resume-journal mechanics are written for dispatched stage agents; an Explore-class child journals nothing, and its findings exist only as a return value in its parent's context. When close died at the session limit, its two audit sweeps had already returned -- that is luck, not design. Had the wall landed mid-sweep, the audit work would have been lost with no record that it ran, and the resuming session would have had no way to know it was owed. Third finding this iteration of the shape 'it never bit because the conditions never coincided', beside the release-note lead-token parser and the unreachable pre-release assertion: a latent hazard that has not fired is still a defect. Deliverable: the protocol states that a sub-agent whose findings the parent will act on must have those findings committed or journaled before the parent proceeds.
