- 2026-08-14 — waiter-predicate-self-match — a session waiting on background work with 'until ! pgrep -f <script>' can never exit: the waiter's own bash -c argv contains the script name, so pgrep -f matches itself and the condition stays permanently true. Attested in this iteration's build batch A against run-smoke.sh, where two such waiters both survived the smoke's terminal line and were still running when TaskStop reported 'Successfully stopped'; the observed cost was the Bash tool's 600s foreground cap absorbing an infinite loop, read from outside as a fixed ten-minute wait. Nothing reds: the work completes correctly and the only symptom is wall-clock, which is why it is invisible to every existing oracle. Sanctioned forms to rule between: the bracket trick 'pgrep -f [r]un-smoke.sh', matching a PID rather than a pattern, or waiting on the work's own artifact. Same family as poll-sleep-guard-steer and waiting-rule-fourth-firing-post-fix, distinct from both: this session chose the documented run_in_background + until pattern correctly and the predicate inside it was the defect.

- 2026-08-14 — port-blockers.sh's PB_SCAN tokenizer treats a here-string as a heredoc and stops scanning: the '<<' guard excludes '<<<' only on the first '<', then the generic redirect branch consumes one '<' and the next iteration sees '<<' followed by the operand's quote, so it captures the operand as a heredoc delimiter that never recurs and skips every remaining line. Measured: 46 of 63 still-shell registered members leave the tokenizer in a broken state at EOF (pending heredoc, unbalanced quote, or unpopped substitution frame) — e.g. check-exec-bit stops at line 16 of 96, check-spec-embedded-source at 20 of 134, check-tree-terms at 29 of 66. A second, independent bug rides with it: inside [[ ]] the ')' closing a command substitution is misread as a case-pattern close (incase() is true whenever dbrack is set), so the frame is never popped and the quoting state corrupts (check-evidence-manifest ends sq=1 sp=1). Consequence: BOTH arms silently under-report — the criterion-7 roster has been a false green for its whole life, and every port cohort sequenced with it rested on it, while --group derives truncated keys. The fix is small (consume '<<<' as one here-string operator; pop when sp>0 before treating ')' as a case close) but it changes the default arm's byte output, so it is a unit rather than an in-flight edit.
