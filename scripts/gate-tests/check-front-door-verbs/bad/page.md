# Try it

```sh
curl -fsSL https://example.test/install.sh | sh -s -- demo
```

Or run `npx checkwright frobnicate`, a verb nothing carries.

A flag before the verb reaches the battery, not `init`: `sh -s -- --profile full`.

The pinned release carries no flag table, so each flag after a released verb is unreleased:

```sh
checkwright init --recipe speckit --frob
```

A profile and a recipe the pinned release lacks, and a profile nothing carries:

```sh
checkwright init --profile delegation --recipe openspec
checkwright init --profile nosuch
```

Run the gate binary with `--measure-commit`, which the pinned release lacks, or `--emit frobnicate`, which nothing carries.
