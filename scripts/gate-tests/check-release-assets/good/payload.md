# Consumer payload

A Release carries the tarball and one archive per roster target, each with its sidecar.

<!-- release-assets: app-{version}.tgz app-{version}.tgz.sha256 app-gates-{version}-{target}.tar.gz app-gates-{version}-{target}.tar.gz.sha256 -->

The line above is the one declaration; the quoted `<!-- release-assets: x -->` here is not one.
