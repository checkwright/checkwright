# Checkwright v0.32.1

*2026-10-24*

Checkwright catches reproducible classes of unsupported claims in coding-agent delivery before merge, and this release makes `npx checkwright` run on native Windows and puts `prove` and the OpenSpec overlap line back on the front door.

| [Knob changes](#knob-changes) | 0 | if you set knobs |

| [Platforms](#platforms) | 0 | if you install on a listed platform |
| [Behavior changes](#behavior-changes) | 0 | if you depend on a listed behavior |

- With Node on native Windows, `npx checkwright init` now runs once the install page's `PATH` block has put Git for Windows' `sh` on your `PATH`.
- The install page shows how to prove the install on your own tree with `checkwright prove`, and the OpenSpec page carries the line that adds the overlap recipe.
- A patch: nothing to reconcile on upgrade.

## Upgrading

Replace the vendored kit directories wholesale at `v0.32.1`, or run `checkwright update`. Regenerate your generated artifacts; each freshness gate that reds prints its own regen command. Then run the full battery.

**No allowed reds.**

The behavior changes above are declared for reading, not a mechanical scan. If a gate reds that this note does not name, the upgrade smoke was supposed to catch it first — [open an issue](https://github.com/checkwright/checkwright/issues), because that is a defect in the release rather than work for you.
