# Checkwright v0.46.0

*2026-11-28*

Checkwright catches reproducible classes of unsupported claims in coding-agent delivery before merge, and this release refuses every install write through a link that resolves to no file or outside the repository before anything is written, `init` included. A link whose target name is not UTF-8 now has its own file rewritten, never a lookalike.

- An install no longer writes a file outside your repository through a link, and refuses such a link before it writes anything.
- `init` now refuses a dangling agent-file link instead of replacing it with its seed.
- A single-component amendment carrying the standard checklist no longer needs an audit stamp or a waiver at build entry.
- No gate is new or stricter, so a clean tree stays green on upgrade.

## Behavior changes

- **every arm that writes a marker block** — a symlinked agent file naming a file whose name is not UTF-8 now has that file rewritten, where the writer used to resolve the link through a lossy spelling and could rewrite another file, one whose name carries replacement characters in those positions. Nothing to do.
- **`--install-lifecycle`, `--emit env-probe` and the personal install** — a `.gitattributes`, env-profile or `info/exclude` link that resolves to no file, or outside its repository, is now refused before anything is written, where the arm used to seed the absent target through the link, creating the file it named outside the repository, and only then refuse. `--install-lifecycle` also no longer writes the agent-file block before that refusal. Nothing to do, unless such a target is a link: point it at a file inside the repository.
- **`init`** — where a selected kit needs the agent file, a `CLAUDE.md` link resolving to no file, or outside the repository, now refuses the install at exit 3 before anything is written, where `init` used to replace a dangling link with its seeded file. Nothing to do, unless your agent file is such a link: create the file it names inside the repository, or remove the link, then re-run.
- **`check-stage-entry`** — a section citation on an amendment's task-list item, such as the Definition of Done's causal-completeness line citing canon-kit's check, no longer counts as a reference to that component. A single-component amendment carrying the standard checklist no longer demands an audit stamp or a waiver at build entry. Nothing to do.
- **`--rewrite`** — an operand reached through a symlinked directory whose name is not UTF-8 now has its own file rewritten, where the write used to name the operand's lossy spelling and could replace another file, one whose name carries replacement characters in those positions. Nothing to do.

## Upgrading

Replace the vendored kit directories wholesale at `v0.46.0`, or run `checkwright update`. Regenerate your generated artifacts; each freshness gate that reds prints its own regen command. Then run the full battery.

**No allowed reds.**

The behavior changes above are declared for reading, not a mechanical scan. If a gate reds that this note does not name, the upgrade smoke was supposed to catch it first — [open an issue](https://github.com/checkwright/checkwright/issues), because that is a defect in the release rather than work for you.
