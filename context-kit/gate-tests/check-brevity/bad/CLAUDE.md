# Brevity fixture — bad

## Shared conventions

- **Terse bullet:** one line, fine.
- **Over budget with pointer:** this bullet runs well past the
  code-point budget across many lines of prose, and it openly
  admits that its full detail already lives in the HANDBOOK
  §Some section that it cites, so the gate flags it — the fix
  is to trim the bullet and lean on the § pointer instead, since
  a resident bullet that restates its owner pays at every session.
- A bullet with no bold name is measured too: this one runs well
  past the code-point budget across several lines of prose, and it
  cites the HANDBOOK §Some section as well, so the gate flags it
  by its line number and its opening text rather than letting a
  missing bold run carry it out of reach of the finding it earns
  at every commit that touches the file it sits in.
